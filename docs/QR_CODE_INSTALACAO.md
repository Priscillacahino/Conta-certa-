# QR Code oficial de instalação

O Conta Certa possui um QR Code oficial que aponta diretamente para a página simplificada de instalação:

`https://priscillacahino.github.io/Conta-certa-/instalar.html`

## Arquivos

- `assets/qrcode-instalacao-conta-certa.png` — QR Code simples.
- `assets/qrcode-instalacao-conta-certa-poster.png` — versão visual para compartilhamento e impressão.

## Uso recomendado

O QR Code pode ser usado em:

- grupo de WhatsApp do residencial;
- prestação de contas;
- comunicados;
- cartazes;
- documentos PDF;
- área comum do residencial.

O QR Code não contém dados privados. Ele apenas direciona para a página pública de instalação da PWA.
