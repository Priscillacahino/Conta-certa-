# Link de instalação rápida

O Conta Certa possui uma página pública específica para facilitar a instalação:

`https://priscillacahino.github.io/Conta-certa-/instalar.html`

## Android

Em navegadores compatíveis, o botão **Instalar Conta Certa** chama o prompt nativo de instalação da PWA. O usuário ainda precisa confirmar a instalação, pois navegadores móveis não permitem instalação silenciosa por segurança.

Se o prompt nativo não estiver disponível, a própria página orienta a usar **Instalar app** / **Adicionar à tela inicial** no menu do Chrome.

## iPhone e iPad

O iOS não permite que um site instale uma PWA automaticamente. A página detecta iPhone/iPad e mostra o caminho:

**Safari → Compartilhar → Adicionar à Tela de Início → Adicionar**

## O que acontece depois

A PWA fica com ícone próprio na tela inicial e abre em modo de aplicativo. O núcleo continua offline-first após o primeiro carregamento.

Não é necessário baixar ZIP, APK ou acessar o GitHub.
